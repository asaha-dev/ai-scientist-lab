# AI Scientist Lab

A hands-on learning journey through modern AI, foundation
models, reasoning, AI systems, and scientific applications.

This repository documents my experiments, technical
implementations, research notes, and evolving understanding
of modern AI.

## Learning goals

- Understand LLM architectures by implementing them
- Explore reasoning, post-training, and model evaluation
- Deploy and benchmark open-weight models
- Build reliable agents for scientific research
- Study biological and multimodal foundation models
- Connect experimental results to research decisions

## Repository structure

- foundations/: Core LLM implementations and experiments
- reasoning/: Reasoning models and post-training
- serving/: GPU deployment and benchmarking
- agents/: Scientific research agents
- biology/: Biological foundation model experiments
- research-notes/: Reading notes and learning journal
- blog/: Longer technical articles
